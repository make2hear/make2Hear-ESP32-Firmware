# Upstream reference

Make2Hear originated from Espressif’s
[A2DP source example](https://github.com/espressif/esp-idf/tree/fff9895c82d744c7237be8847347bdd1b07c6643/examples/bluetooth/bluedroid/classic_bt/a2dp_source).

That example demonstrates generated audio and a periodic stop/reconnect cycle.
Make2Hear captures INMP441 audio continuously and uses a different PCM format.
Follow the [Make2Hear README](../README.md) for setup and current behavior.
Upstream attribution is in [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md).
